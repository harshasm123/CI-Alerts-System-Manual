║                           DATA FLOW SUMMARY                                          ║
╠══════════════════════════════════════════════════════════════════════════════════════╣
║  1. EventBridge triggers ingestion Lambdas at midnight UTC                           ║
║  2. Ingestion Lambdas fetch data from external APIs → SQS Queue                      ║
║  3. Processor Lambda consumes SQS messages → Amazon Nova Lite analysis               ║
║  4. AI-generated insights stored in DynamoDB InsightsTable                           ║
║  5. EventBridge triggers Digest Lambda at 9 AM UTC                                   ║
║  6. Digest Lambda queries user watchlists → generates personalized emails            ║
║  7. SES sends daily digest emails to verified users                                  ║
║  8. Users access React UI via CloudFront → Cognito auth → API Gateway               ║
║  9. API Gateway validates JWT → Lambda functions → DynamoDB CRUD operations          ║
